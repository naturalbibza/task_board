Правила работы:
- Фаза закрывается только после своего чекпоинта; следующий коммит — `docs: phase N done`.
- Параллелить внутри фазы можно, между фазами — нельзя (зависимости).
- В конце каждой фазы обновлять этот файл (отметки ✅ и найденные отклонения).
- **Правило раннего деплоя:** с фазы 2 приложение живёт на VPS (https://bibza.ru).
  С фазы 3 деплоит CI/CD: пуш в `main` после закрытия фазы обновляет прод; чекпоинт
  каждой фазы проверяется и на проде.
- **Не коммитить и не пушить самостоятельно** — только по явной просьбе пользователя.
