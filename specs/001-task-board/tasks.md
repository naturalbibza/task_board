# Задачи: Коллаборативная доска задач

- Статус: draft → выполняется по фазам
- Спека: [spec.md](./spec.md) · План: [plan.md](./plan.md)

Правила работы:
- Фаза закрывается только после своего чекпоинта; следующий коммит — `docs: phase N done`.
- Параллелить внутри фазы можно, между фазами — нельзя (зависимости).
- В конце каждой фазы обновлять этот файл (отметки ✅ и найденные отклонения).
- **Правило раннего деплоя:** начиная с фазы 2 приложение живёт на VPS. Каждая
  фаза, начиная с фазы 3, заканчивается ре-деплоем (🔁) — прод всегда в состоянии
  последней принятой фазы, преподавателю есть что показать в любой момент.

## Фаза 4. WebSocket-канал: подключение и снапшот (FR-9)

- [ ] 4.1 Протокол в `shared`: zod-схемы всех intents/events (§6 плана) — единственный контракт

- [ ] 4.3 `board:join`: проверка членства, комната `board:<id>`, `board:state` — снапшот из БД
- [ ] 4.4 Клиент: socket-синглтон, авто-reconnect, замена REST-снапшота экрана доски на `board:state`
- [ ] 4.5 Presence: `presence:update` (список в комнате) + компонент MembersBar
- [ ] 4.6 🔁 Ре-деплой; проверить WSS-проксирование через Caddy на проде
